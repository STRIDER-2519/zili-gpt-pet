# 制作记录

紫璃的角色与动作画面使用内置 imagegen 生成和修正；本项目没有附带模型、API Key 或自动图片生成服务。采用的高分辨率源图保存在 `source-art/`，实际提示词保存在 `prompts/`。

| 文件 | 用途 |
| --- | --- |
| `source-art/character-base.png` | 白发紫瞳、龙角、紫色龙翼、裙装的身份参考 |
| `source-art/idle-source.png` | 趴卧待机源图，原图为分格布局 |
| `source-art/running-right-source.png` | 舒展尾巴的右跑源图，原图为分格布局；左跑按帧镜像 |
| `source-art/tiger-hat-drum-source.png` | 传统红色虎头帽、鹿角与拨浪鼓等待动作 |
| `source-art/jumping-v3-source.png` | 修正后的五帧直立小跳 |

源图经过移除背景、统一比例、定位和边缘清理后组装。完整透明图集才是导入成品。当前图集经过精确字节结构校验、九组帧检查、完整质量检查、独立有序帧审阅和 Pets 服务校验，保存后的 RGBA 像素也与本地成品一致。

传统虎头帽的最终造型参考用户提供的照片：红色绣布、大虎眼、青绿眉饰、金色纹饰、白色毛边、绒球与浅棕鹿角。原始参考照片未纳入公开包。紫璃自己的白色龙角一并保留。

制作规范的状态动图与原生实际调度不同：本次另行核对了客户端触发优先级及三遍短动作策略。相关行为总结在 [动作说明](动作说明.md)，时长数据在 `verification/native-timing.json`。未把静态代码检查或离线预览称为原生界面实机录屏。

公开交付对原制作目录作了白名单整理：不包含云端宠物 ID、签名链接、个人计时数据、账号文件、原生宿主源码或第三方插件脚本。面板源码与素材工具使用项目相对路径。
