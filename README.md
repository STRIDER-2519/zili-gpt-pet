紫璃 · 中文使用说明

## 先分清两部分

**原生紫璃**是在支持自定义宠物的 ChatGPT / Codex 原生客户端中显示的小龙娘。**离线计时面板**是另外提供的 Windows 小程序，用于计时与提醒；它不会安装原生宠物，也不会自动跟随紫璃的位置。

本交付包含 v3 图集、原生本地宠物描述文件与 Windows 安装脚本。Windows 当前本地宠物格式已按 26.1007.2314.0 版本核实；脚本已在独立测试目录中验证，不会默认激活或替换其他宠物。不同版本的设置名称和功能入口可能不同。

## 一、安装原生紫璃（Windows）

1. 完整解压交付包，不能直接在 ZIP 里运行脚本。
2. 双击项目根目录 **`安装紫璃.cmd`**。安装成功后，窗口会提示文件所在目录。
3. 打开原生客户端的 **Settings / 设置 → Pets 或 Mini & Pets / 宠物**。
4. 点击 **Refresh / 刷新**，在自定义宠物中选择 **紫璃 v3**。
5. 使用客户端的 **Show pet / 显示宠物**，或在支持命令的输入框中输入 `/pet`，显示悬浮宠物。

安装只复制两份文件：`pet.json` 与 `spritesheet.png`。不需要管理员权限、不登录账户、不调用额度接口，也不自动改动当前选中的宠物。

脚本默认安装到当前用户的 `.codex/pets/zili-gpt-pet/`；如果配置了 `CODEX_HOME`，则使用该目录下的 `pets`。使用自定义目录、远程环境或 WSL 的用户，应以客户端实际打开的宠物目录为准，按下面的方法手动安装。

### 不运行脚本的手动安装

1. 在宠物设置中找到 **Custom pets / 自定义宠物 → Open folder / 打开文件夹**。
2. 把交付包中 `pets/` 下的整个 **`zili-gpt-pet`** 文件夹复制进去。不要只复制图片，也不要再套一层 `pets`。
3. 回到设置，点 **Refresh / 刷新**，再选择 **紫璃 v3**。

最终应是：

```text
客户端的 pets 目录/
└─ zili-gpt-pet/
   ├─ pet.json
   └─ spritesheet.png
```

没有“打开文件夹”按钮时，Windows 默认目录可在文件管理器地址栏输入 `%USERPROFILE%\.codex\pets` 打开；如果使用了自定义 `CODEX_HOME`，请使用其实际 `pets` 子目录。

### 更新、恢复与卸载

- **更新本交付版**：使用新版交付包的 `更新紫璃.cmd`，再刷新宠物列表。更新会将旧的本地文件夹备份到相邻的 `pet-backups/`。普通安装脚本遇到同名目录会停止，不会直接覆盖。
- **恢复旧版**：关闭悬浮宠物，将备份中的原 `pet.json` 和 `spritesheet.png` 放回同一个 `zili-gpt-pet` 文件夹，再刷新列表。
- **卸载本交付版**：先选择其他宠物或隐藏宠物，在客户端实际 pets 目录中移走 `zili-gpt-pet` 文件夹，刷新列表。无需删除整个 `.codex` 或其他宠物目录。
- 本地导入与云端 Work 宠物是不同保存方式，不自动同步。若已有同名云端紫璃，本交付版在列表中显示为 **紫璃 v3**，便于区分。

## 二、动作怎么触发

| 操作或状态 | 动作 |
| --- | --- |
| 待机或短动作结束 | 趴着休息 |
| 鼠标进入角色区域 | 直立小跳三次，再回待机 |
| 按住左右拖动 | 左右跑步 |
| 初次唤醒 | 挥手 |
| 任务处理中 | 思考工作 |
| 等待输入或审批 | 戴传统虎头帽，轻摇拨浪鼓 |
| 任务失败／完成 | 低落／检查成果 |

拖动优先于悬停，悬停优先于任务状态。鼠标移出可能直接中断动画；现有看向鼠标的画面仍是站姿。更完整的时序和限制见 [动作说明](动作说明.md)。

## 三、使用离线计时面板（可选）

1. 解压 `downloads/zili-companion-v0.3-windows.zip` 到自己可以写入的文件夹。
2. 双击 **`紫璃陪伴面板.exe`**。
3. 拖动面板顶部，手动放在原生紫璃旁边。面板不会自动跟随宠物。

请保留同目录的 `Panel.xaml` 和 `assets/`，不要只移动 EXE。面板适用于 Windows 10 / 11，使用系统 .NET Framework；无需 Python、API 密钥或账号登录。

### 常用操作

- 默认显示小卡片：本次陪伴时间、暂停按钮。
- `Ⅱ` 暂停，`▶` 继续；`⋯` 展开今日累计与提醒设置，详情中的 `−` 收起。
- 默认连续陪伴 45 分钟后提醒休息，可在详情改为 1–240 分钟。
- “稍后 5 分钟”延后提醒；“我休息啦”暂停计时并重置连续周期；“关闭提醒”停止提醒，可在详情重新开启。
- `×` 退出。下次启动本次时间重新计，今日累计与设置保留。

统计口径是**面板打开且未暂停的时间**，包括在其他软件工作的时间；锁屏与休眠不计入。它不等于实际聊天时长或专注时长。

记录只保存在面板同目录的 `data/`。升级或移动面板时保留自己的 `data/`；不要把这些个人记录上传到仓库。关闭面板不会关闭原生紫璃。

## 四、常见问题

**刷新后没有紫璃**：检查是否放进客户端实际使用的 pets 目录，目录内是否直接包含 `pet.json` 和完整 PNG；确认客户端支持 v2。自定义环境不要只按默认 Windows 路径判断。

**出现两个紫璃**：一个可能是已存在的云端宠物；本交付本地版本显示“紫璃 v3”。安装不会替你删除或切换原来的宠物。

**只显示静态图**：检查系统是否开启减少动态效果；该模式下原生客户端会显示静态帧。

**网页版上传提示尺寸不支持**：此包是 1536×2288 的 v2 图集，不要自行裁成旧格式来绕过校验。使用支持 v2 的原生本地导入方式。网页与本地原生宠物的入口、支持布局和保存方式可能不同。

**面板打不开**：先完整解压，确认 EXE、`Panel.xaml`、`assets/` 齐全，放到可写目录。若出现 `startup-error.txt`，查看其中错误；也可按 [开发说明](开发说明.md) 从源码编译。不要在 ZIP 内直接启动。

**想自动随机戴帽或禁用悬停跳跃**：当前图集不能设置这些规则；虎头帽对应等待输入状态，鼠标事件由原生程序控制。

## 五、其他平台与官方资料

图集及预览可在其他平台查看。当前 Windows 本地导入格式已核实，macOS 未在本次交付中实机验证；计时面板仅支持 Windows。

官方入口及平台差异可参考 [OpenAI 官方 Pets 说明](https://learn.chatgpt.com/docs/pets)。官方说明涉及不同产品入口，应结合自己的客户端版本操作。
